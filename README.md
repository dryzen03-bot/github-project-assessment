# github-project-assessment
Критерии оценки проектов по программированию на GitHub

Данный репозиторий содержит разработанную систему критериев оценки проектов студентов, размещённых на платформе GitHub.
## Цель
Создание объективной системы оценивания проектов по программированию с учётом:
- качества кода
- структуры проекта
- документации
- использования GitHub

## Состав репозитория
- rubric.md — критерии оценивания
- checklist.md — чек-лист проверки проекта
- evaluation-form.md — шаблон оценочного листа

## Как использовать
1. Открыть репозиторий студента
2. Проверить по чек-листу
3. Оценить по рубрике
4. Заполнить оценочный лист

## Система оценивания
Максимальный балл: **100**
